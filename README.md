# Student Fee Details Portal

A web application with HTML, CSS, JavaScript, and Python (Flask) for managing student details with primary-key-based database integration.

## Features
- Collects Name, Roll No., and Total Fee in Rupees
- Save, Clear, and Delete functionality with confirmation dialogs
- Designed with monospace typography and custom minimal styling
- Python Flask backend ready for Supabase integration

## Setup
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run backend:
   ```bash
   python app.py
   ```
